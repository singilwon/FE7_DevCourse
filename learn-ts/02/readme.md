## 타입에 관한 것

- 타입추론 : 타입을 명시하지 않아도, 컴파일러가 값, 문맥, 흐름을 보고 적절한 타입을 자동으로 결정하는 기능
- 타입을 지정할 때 string 이런 게 아니라 "hello" 이런 식으로 지정하면 그 변수는 "hello" 값 빼고는 아무것도 지정이 안됨(리터럴 타입)
  - 그래서 TS에서 const도 저장되는 게 이런 원리로 지정됨
  - 참조 자료형은 이런 거 없이 그냥 범용적으로 지정이 됨
- 객체는 변수에 커서 올리면 객체의 타입이 자동을 타입추론으로 짜져서 보임, 그거 복붙해서 써도 됨
- api에서 뭔가를 받아올 때 json()을 하고 그 json에 타입을 미리 명시해주면, 출력하거나 그럴 때 자동완성이 나와서 편해짐

## 함수 타입 지정하는 방법

- 함수의 매개 변수와 반환 값의 타입을 지정하는 것
  ```
  function sum(n1: number, n2: number): number {}
  // 이렇게 매개변수 옆에 써주고, () {} 사이에 return의 타입을 써줌
  ```
- 반환값은 자동으로 추론됨(그래서 명시해도 되고 안 해도 되고), 근데 매개변수 타입추론은 불가

### void, never(특수타입)

- return 값이 없는 함수는 반환 타입에 undefined 써도됨
- void : 이게 함수의 반환값 타입 지정에만 사용하는 건데, 함수가 return 하는 게 없을 때 쓸 수 있음
- never : 값을 절대로 반환하지 않는 함수에 쓰인는 것
- 차이점 : void는 할 수 있는데 안 한 것, never는 반환을 할 수 없을 때

### 여러가지 기호

- 옵셔널(? 기호) : 매개변수에 ? 활용, 2개 매개변수 있는 곳에서 하나만 보내고 싶을 때는 매개변수 앞에 ?를 써준다
  - 옵셔널 기호를 첫 매개변수에는 쓸 수 없음
- 유니언 타입(| 기호) : A 또는 B타입, 2가지 타입 중에 하나 와도 되는 것
- 인터섹션 타입(& 기호) : 기본타입에는 보통 사용 X, 보통 객체 타입에 많이 사용
  - 2개의 타입을 모두 만족해야 되는 것, 예시는 02.ts에

### 타입가드

- 유니언 타입에 메서드 쓰고 싶으면 써야됨
- 런타임에 실제 검사 결과를 바탕으로 변수의 타입을 조금 더 좁게 추론하도록 타입스크립트에 힌트를 주는 문법
- if문에 typeof를 써서 통과가 되면 메서드를 쓸 수 있는 방식으로 하는 것(유니언 타입으로 하면 그게 안됨)

### 함수 오버로딩

- 오버로드 시그니처를 활용해서 매개변수와 반환값의 경우의 수를 좁히는 방법
- 함수 구현부 제외한 선언부분만 따로 적어서 ;를 쓴다
- 매개변수의 타입이 어떤 것과 어떤것이 넘어오면, 반환값은 어떤 것인지 미리 적어두는 느낌
  - 이렇게 하면 타입가드가 딱히 필요없이 쓸 수 있음

### 그 외 함수관련

- 반환값이 함수이면 이런 식으로 반환 타입에 반환되는 함수의 타입들도 써줘야함
  ```
  function createMultiplier(factor:number):(num:number)=>number {
  return (num) => num *factor;
  }
  const multiplyByTwo = createMultiplier(2);
  console.log(multiplyByTwo(5));
  ```
- ...arr 이 매개변수는 배열이니까 배열타입으로 받아야함
