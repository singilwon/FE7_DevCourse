## 타입 별칭(02.ts)

- 나만의 커스텀 타입을 만들 수 있는 방법 제공(내가 들어가는 타입을 정해서 묶음을 하나 만드는 느낌)
- 장점: 유지보수성, 가독성 올라감
- TS는 인터프리티 언어가 아니라 어디서 선언을 했던지 상관없이 적용이 됨
- 예시
  ```
  type Person = {
      name: string;
      age: number;
      gender: string;
  };
  ```
- 관례 : 항상 type 변수의 첫 글자를 대문자로 함
- 6가지 타입 별칭 예시까지 02.ts폴더에 있음(타입 확장 포함)

### 짧은 개념(01.ts)

- 구조적 타이핑 : 타입의 이름이나 선언이 아니라, 내부의 구조가 같으면 같은 타입으로 간주하는 방식
- readonly : 수정을 불가능하게 해주는 것(?에도 쓸 수 있음)
- 인데스 시그니처 : 객체의 키와 값의 타입 패턴을 통해 타입을 정의하는 문법

```

[key: type]: type;

```

- 단점은 객체.을 찍었을 때 어떤 속성이 있는지 보이는데, 얘는 안 보임
- 키 값에 string은 항상 string(javasciprt 설계 자체가 객체 키는 모두 문자형으로 변환되도록 설정됨)
- 함수도 일급 객체라 타입을 객체처럼 정할 수 있지만, 굳이 안 한다.

## 인터페이스(0.3ts)

- 객체의 타입을 지정할 때 사용하는 타입 지정 방법
- 같은 이름으로 지정을 하면 자동으로 병합이 됨

  ```
    // 자동 병합
  interface Person {
    name: string;
  }

  interface Person {
    // 같은 이름으로 지정하는 게 가능
    age: number;
  }
  const person: Person = {
    name: "kim",
    age: 20,
  };
  ```

### 상속

- 상속 : interface 식별자 extends 다른식별자를 붙이면 상속이 됨
- 다중 인터페이스 상속 : 한 인터페이스가 다른 여러 인터페이스를 상속받을 수 있음
  - extends 식별자1,식별자2
